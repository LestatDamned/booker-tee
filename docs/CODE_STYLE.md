# Стиль кода Booker Tee

Статус: действующий проектный контракт для изменений кода.

## Объекты и функции

Прикладные и доменные действия по умолчанию оформляются как методы объектов:
`Actor.action()` — класс отвечает на вопрос «кто выполняет действие», метод —
«что он делает».

Примеры:

- `StatementImporter.import_document()`;
- `OperationConfirmer.confirm()`;
- `ReportBuilder.build()`.

Не создавайте свободную функцию, если действие:

- имеет естественного владельца в предметной области;
- использует зависимости;
- управляет состоянием или жизненным циклом;
- оркестрирует несколько шагов;
- обеспечивает бизнес-инвариант.

Свободная функция допустима, когда она:

- является чистым преобразованием без состояния и зависимостей;
- не имеет естественного владельца;
- требуется интерфейсом библиотеки или фреймворка;
- проще и понятнее искусственного класса.

Не создавайте `Utils`, `Helpers` и классы только со статическими методами ради
соблюдения формы `Class.action()`. Класс должен представлять реальную
ответственность, состояние или набор зависимостей.
