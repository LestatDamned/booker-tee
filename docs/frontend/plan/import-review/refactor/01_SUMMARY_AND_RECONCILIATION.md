# Этап 1. Компактная сводка и сверка

Статус: completed.

## Цель

Показать контекст документа, progress и главный итог сверки до начала очереди,
не занимая ими весь первый экран.

## Реализовано

- единая компактная сводка страницы;
- название документа и пользовательское название привязанного счёта;
- progress, число нерешённых строк и переход к следующей строке;
- поступления, списания и однозначный статус сверки;
- корректное состояние объяснённой исключёнными строками разницы;
- раскрываемые финансовые расчёты и отдельно вложенные технические показатели;
- компактная иерархия действий документа.

## Критерии готовности

- [x] Начало очереди видно сразу или после минимальной прокрутки на desktop.
- [x] Статус строится из существующих reason codes и сумм, без hardcode примера.
- [x] `Сверка поступлений` и `Сверка списаний` читаются как финансовый расчёт.
- [x] Технические counts не конкурируют с результатом.
- [x] Недоступные totals имеют спокойное объяснение.

## Evidence

- Feature tests покрывают match, explained mismatch и unavailable totals.
- Desktop/tablet/mobile UI audit пройден после реализации.
