# Этап 7. Ручное создание правила

Статус: pending.

## Цель

Дать пользователю полный контроль над устойчивым фрагментом шумного банковского
описания и заранее показать результат создаваемого правила.

## Scope

- Действие называется `Применять это решение к похожим строкам`.
- После включения показываются полное исходное описание и поле
  `Фрагмент описания`.
- Pattern не подставляется автоматически.
- Пользователь копирует и вставляет устойчивый фрагмент самостоятельно.
- Preview: `Если описание содержит «…» → категория «…»`.
- Пустой pattern блокируется до posting клиентом и command boundary.

## Критерии готовности

- [ ] Полное описание доступно рядом как справка.
- [ ] Поле имеет видимый label, helper text и локальную ошибку.
- [ ] Ничего не сохраняется без явного согласия пользователя.
- [ ] Rule creation и posting сохраняют текущую atomicity.
- [ ] Созданное правило не подтверждает похожие строки автоматически.
