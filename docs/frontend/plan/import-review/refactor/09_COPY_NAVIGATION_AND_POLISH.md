# Этап 9. Тексты, фильтры, навигация и визуальная полировка

Статус: pending.

## Цель

После стабилизации структуры провести сквозную редактуру и устранить остаточные
разрывы в визуальном языке страницы.

## Scope

- Отредактировать все русские labels, helper text, empty/error/status copy.
- Заменить технические и канцелярские формулировки на результат или действие.
- Проверить filters: основной рабочий фильтр — нерешённые строки, если это не
  меняет бизнес-семантику очереди.
- Фильтры остаются непосредственно над очередью.
- Улучшить active state и группировку AppShell navigation без конкуренции с
  рабочей областью.
- Проверить размеры даты и суммы, вес описания, spacing, density и контраст.
- Проверить отсутствие повторов, лишних карточек и постоянно раскрытых
  технических данных.

## Целевые формулировки

- `Сверка поступлений`, `Сверка списаний`;
- `Проверить операцию` / `Изменить операцию`;
- `Фрагмент описания`;
- `Применять это решение к похожим строкам`;
- `Следующая нерешённая строка`;
- `Есть необъяснённая разница` только при реальной необъяснённой разнице.

## Критерии готовности

- [ ] В ordinary flow нет parser/internal terminology без пользовательской
      пользы.
- [ ] Filters однозначны и имеют корректные counts/pressed semantics.
- [ ] Active navigation видна, но спокойнее рабочей области.
- [ ] Contrast, focus, touch targets и reduced motion проверены.
- [ ] Пройдены все frontend checks и полный relevant UI audit.
- [ ] Зафиксирован финальный desktop/tablet/mobile screenshot set.
