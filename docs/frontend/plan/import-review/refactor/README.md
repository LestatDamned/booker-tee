# Import Review UI Refactor

Статус: active execution plan.

Этот каталог — рабочий план полировки React-страницы «Проверка выписки» после
завершения функциональной миграции Import Review. Он переводит исходный
UX-промт в последовательные, отдельно принимаемые этапы и фиксирует уже
выполненную работу.

## Цель

Пользователь должен быстро просматривать строки выписки и по каждой строке
понимать:

1. что произошло;
2. какое решение предлагает система;
3. почему предложено это решение;
4. что будет создано после подтверждения;
5. как подтвердить или изменить результат.

Import Review остаётся `bank-feed reconciliation workbench`, а не CRUD-таблицей
и не техническим интерфейсом парсера.

## Как работать с планом

- За один цикл выполняется только один этап.
- Переход к следующему этапу требует отдельного подтверждения пользователя.
- После реализации обновляются статус этапа и чек-лист в этом файле.
- Каждый этап завершается перечнем файлов, скриншотом, тестами и известными
  ограничениями.
- UI не вычисляет financial truth, permissions, lifecycle или confirmability.
- Новые компоненты создаются только при отсутствии подходящего существующего
  контракта.

## Принятые решения

- Сохраняем текущую геометрию `WorkbenchRow`: строки не переводятся в таблицу с
  заголовками колонок без отдельного решения.
- Доход, расход и перевод различаются семантическим цветом и текстом.
- Категория, статус и источник решения имеют разные визуальные роли.
- Пользовательские названия счетов берутся из БД; реквизиты выписки не заменяют
  их в обычном интерфейсе.
- Перевод является основным сценарием разбора и доступен без меню редких
  действий.
- Текст pattern для нового автоправила пользователь вводит самостоятельно.
- Технические raw/normalized данные доступны через progressive disclosure.

## Общий Definition of Done

- Financial truth и business policies не дублируются в React.
- Результат показан до destructive или financial mutation.
- Цвет не является единственным носителем смысла.
- Основное действие одно; secondary и danger действия разделены.
- Интерактивные зоны не меньше 44 px, focus видим, disclosure имеет корректные
  ARIA-атрибуты.
- Нет горизонтального overflow на `390×844`, `920×900`, `1440×1000`.
- Пройдены feature tests, TypeScript, lint, style check, production build и
  relevant UI audit.
